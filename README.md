## ✨ Key Features

- **🌓 Pure CSS Light & Dark Theme Toggle:**  
  Seamlessly switches between *Cosmic Dark* and *Crisp Light* modes using pure CSS `:has(#theme-toggle:checked)`. Designed with an overlay toggle inside the floating navbar to eliminate page-scroll jumps.

- **🔍 Click-to-Zoom Lightbox Modals:**  
  Clicking any project preview opens an enlarged high-resolution screenshot modal. Built with pure CSS checkbox states (`:checked`) with multiple dismiss options (close button, dismissal pill, or clicking the frosted backdrop).

- **🧭 Dynamic Active Navigation Highlighting:**  
  The floating pill navbar automatically highlights the active section in bright cyan/blue using CSS `:target` and `:has()` selectors.

- **📱 Fully Responsive (CSS Grid & Flexbox):**  
  Adapts across all screen sizes (tested at 1920×1080 desktop down to 375×812 mobile) with clean reflow and readable typography.

- **🛡️ 100% Academic & EWB Compliance:**  
  Zero JavaScript, semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), valid heading hierarchy (`h1`–`h4`), descriptive `alt` tags, and a visual demo contact form disclaimer.
